## 1. GitHub Copilot Fusion
**공식 출처:** [GitHub Changelog](https://github.blog/changelog/?label=copilot&opened-months=2)

**[사실]** 2026-10-28 changelog에 “Route and orchestrate models with GitHub Copilot Fusion”이 게시됐다.  
**[해석]** model routing은 동일 task의 모델·patch·검증 결과 분산을 만들 수 있으므로, quality claim 이전에 route audit를 확인해야 한다.

| 점검 축 | 판정 |
|---|---|
| 문제/기능 | model routing 및 orchestration |
| 사용자/workflow | GitHub/Copilot 조직의 PR review·issue triage·repo automation |
| 최근성/유지보수 | GitHub 공식 changelog로 확인 |
| 설치·가격·license | 이번 원문만으로 미확인 |
| API·CLI·MCP | 미확인 |
| 데이터·권한 | repository context 및 조직 policy 영향 가능성 |
| 보안 | route별 처리 경로와 context exposure audit 필요 |
| 재현성 | 동일 prompt route/result의 변동을 기록해야 함 |
| 도입 판단 | 관찰 대상, 전면 도입 보류 |

**측정 가능한 10–30분 trial:** 동일 bug-fix prompt 10개로 선택 model/route, 수정 LOC, test pass rate, human intervention을 기록한다. 모든 실행의 route가 남고 test pass rate가 고정 단일 모델보다 낮지 않으며 intervention이 늘지 않으면 다음 단계로 간다. route 설명 불가 또는 결과 분산 증가 시 중단한다.

**권한/보안/유지보수:** 조직 policy·repository context 접근·로그 retention을 확인하기 전에는 public sandbox repo에만 쓴다. 이번 원문만으로 API·비용·rollout 조건을 확정할 수 없으므로 설치하지 않아도 된다.

## 2. Dapr Agents v1.0.6
**공식 출처:** [dapr/dapr-agents releases](https://github.com/dapr/dapr-agents/releases)

**[사실]** 공식 GitHub release는 v1.0.6과 DurableAgent용 Drasi extension을 표시한다.  
**[해석]** durable/event-driven agent는 연구 자동화에 유용할 수 있으나, idempotency guard가 없으면 heartbeat/release event replay가 duplicate write를 낼 수 있다.

| 점검 축 | 판정 |
|---|---|
| 문제/기능 | durable agent의 event/state 기반 실행, Drasi extension |
| 사용자/workflow | event-driven research ops, artifact registry, monitor |
| 최근성/유지보수 | tagged GitHub release 확인 |
| 오픈소스 | 공개 GitHub repository |
| 가격·모델·API·CLI·MCP | 이번 원문만으로 미확인 |
| 데이터·권한 | event source와 state-store write scope에 의존 |
| 보안 | side effect, state retention, event payload 노출 |
| 재현성 | event ID replay와 deterministic transition 시험 필요 |
| 도입 판단 | sandbox trial 후보, production write 보류 |

**측정 가능한 10–30분 trial:** 같은 event ID를 3회 replay하여 생성 파일 수, state transition 수, 외부 write 수를 기록한다. 외부 write 1회·결정적 state·replay log가 남으면 통과다. duplicate file/notification 또는 state divergence가 나면 중단한다.

**권한/보안/유지보수:** production repository write 권한은 trial에 부여하지 않는다. state store retention과 payload의 source URL/metadata를 확인한다. 현재 파일 API+ledger 자동화보다 idempotency와 observability가 실제로 개선된 경우에만 도입한다.

## 패턴과 권고
agent 능력 경쟁보다 model routing·organization policy·durable event execution 같은 운영 제어층이 차별점이 되고 있다. 연구 workflow에서는 “어떤 모델이 어떤 권한으로 무엇을 실행했고 어떤 근거를 남겼는가”가 핵심이다. Copilot Fusion은 route audit, Dapr Agents는 replay/idempotency trial을 통과하기 전 write 권한을 확대하지 않는다.
