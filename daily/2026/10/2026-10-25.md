## 3. Microsoft Agent Framework Python 1.23.0 / .NET 1.26.0

1. **정확한 이름**: Microsoft Agent Framework, Python 1.23.0 및 .NET 1.26.0.
2. **공식 저장소/사이트**: [microsoft/agent-framework](https://github.com/microsoft/agent-framework), [Microsoft Learn](https://learn.microsoft.com/en-us/agent-framework/).
3. **범주**: production agent 및 multi-agent workflow 프레임워크.
4. **정확히 하는 일**: Python/.NET에서 agent, graph orchestration, provider integration, state·observability·human-in-the-loop 패턴을 제공한다. **확인된 사실**이다.
5. **해결 문제**: prototype agent를 지속 가능하고 관찰 가능한 workflow로 옮기는 공통 기반을 제공한다.
6. **지원 클라이언트**: Python, .NET; README는 Go SDK를 별도 저장소로 안내한다.
7. **설치 방법**: PyPI `agent-framework` 또는 NuGet `Microsoft.Agents.AI` 계열 패키지. 정확한 extra는 사용 provider 문서에 맞춰야 한다.
8. **오픈소스 여부**: 예.
9. **라이선스**: MIT.
10. **로컬/클라우드**: 로컬 개발과 cloud hosting 모두 가능하며 Azure OpenAI, OpenAI, GitHub Copilot SDK 등과 통합된다.
11. **계정/API 키**: 선택한 모델/provider에 따라 계정·API key 또는 Azure/GitHub 인증이 필요하다.
12. **읽기 권한**: 프레임워크 자체 권한은 연결한 tool과 data source에 종속된다.
13. **쓰기 권한**: 연결한 tool이 허용한 범위에서만 발생한다. 기본 package만으로 임의 filesystem 쓰기를 한다는 근거는 없다.
14. **shell/browser/Git/filesystem/network**: 모두 tool/provider 구성에 따라 달라진다. network는 원격 모델 사용 시 필요하다.
15. **보안/개인정보**: metadata forwarding, tool invocation, provider telemetry 경계를 설계해야 한다. A2A metadata의 allowlist forwarding이 1.23.0에 추가됐다.
16. **최근 업데이트 날짜**: Python 1.23.0은 2026-10-22, .NET 1.26.0은 2026-10-23 공개.
17. **릴리스/중요 커밋**: [Python 1.23.0](https://github.com/microsoft/agent-framework/releases/tag/python-1.23.0)은 A2A argument forwarding과 synthetic trailing user turn을 추가했다. [.NET 1.26.0](https://github.com/microsoft/agent-framework/releases/tag/dotnet-1.26.0)은 package update와 Anthropic multiple tool-call 관련 변경을 포함한다.
18. **활동성**: 14k+ star, 800개 이상 open issue, 10/24까지 커밋이 이어지는 대형 활성 프로젝트다.
19. **이슈/PR 상태**: [#9675](https://github.com/microsoft/agent-framework/issues/9675)는 `execution.taskSupport=optional` MCP tool이 skip되는 문제, [#9676](https://github.com/microsoft/agent-framework/issues/9676)은 Ollama streaming tool call의 finish_reason 오판을 보고했다.
20. **문서 품질**: MS Learn, sample, 언어별 package 문서가 있어 높음. 빠른 변경 때문에 버전 일치 확인이 필요하다.
21. **코드/테스트 품질**: dependency bounds test 수정과 release automation이 확인된다. 모듈별 coverage 수치는 확인되지 않았다.
22. **무료/유료**: framework는 무료 MIT. 모델·호스팅·Azure 비용은 별도.
23. **장점**: 다중 언어, orchestration pattern, provider 선택, production 운영 기능, 큰 생태계.
24. **단점**: 추상화와 dependency 규모가 크고, 최신 릴리스에도 MCP/Ollama edge case가 남아 있다.
