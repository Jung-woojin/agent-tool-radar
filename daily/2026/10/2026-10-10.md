## 오늘은 굳이 설치하지 않아도 되는 것

- **FastMCP 4.1.0:** 전일 이미 Top 3로 평가했고 오늘 새 릴리스가 없다. 기존 trial 결과를 먼저 보는 편이 낫다.
- **Cline SDK 0.0.92 / Desktop 0.0.45:** MCP `EPIPE` 등 의미 있는 수정은 전일 보고서 범위에 이미 포함됐다. 현재 Cline을 쓰지 않는다면 새로 추가할 이유가 약하다.
- **GitHub MCP Server 2.0.2:** typed header validation 복구는 중요하지만 어제 다뤘고 추가 변화가 없다.
- **LangGraph CLI 0.4.33:** 최근 변화는 있으나 오늘 선정 도구보다 사용자의 즉시 권한·재현성 문제를 덜 줄인다.
- **OpenCode 1.18.35:** 유용한 stats output 변화가 있지만 엄격한 72시간 창에서 약 3시간 벗어났다.
- **OpenAI Agents Python 0.23.1, AutoGen 0.7.5, smolagents 1.26.0:** 최신 공식 릴리스가 오늘의 72시간 창 밖이다.
- **n8n 신규 설치:** 이미 n8n으로 복수 SaaS workflow를 운용할 계획이 없다면 오늘 패치는 신규 도입 사유가 아니다. 기존 사용자의 migration 검사에 더 가깝다.
- **CrewAI 신규 설치:** 한두 단계 연구 자동화에는 multi-agent orchestration이 과하다. 먼저 PydanticAI나 단일 coding agent로 baseline을 만든 뒤 비교하는 편이 낫다.

## 전일 대비 생태계 변화

전일은 FastMCP·Cline·GitHub MCP처럼 **도구 연결부와 context 압축**이 중심이었다. 오늘은 연결된 도구가 실제로 실패했을 때의 **secret redaction, policy 적용, lock ownership, durable identity, session evidence**가 중심으로 이동했다. 이는 agent 생태계가 기능 경쟁에서 운영 신뢰성 경쟁으로 넘어간다는 단서지만, 하루치 릴리스만으로 장기 추세라고 단정하지는 않는다.

내일 확인할 신호는 세 가지다. Claude Code의 보안 수정에 후속 regression report가 나오는지, PydanticAI 2.55.0의 Python 3.11 전환이 ecosystem 호환성 이슈를 만드는지, Browser Use의 Claude toolset이 실제 공개 SDK에서 사용 가능해지는지다.
