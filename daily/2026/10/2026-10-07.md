## 조사 범위·중복·운영 상태

현재 AI Tool Radar와 나머지 9개 예약은 로컬 설정에서 ACTIVE다. 앱의 scheduler last_run은 제공되지 않아 unknown이며, 실행 ledger와 구분했다. 오늘 경로의 원격 추적 파일과 동일 marker Issue는 확인 시 없었다. 최신 기존 도구 보고서는 10월 2일이고, 저장소 최신 commit은 10월 6일의 운영 문서 아카이브다. 이것을 일간 보고서 완료로 계산하지 않았다. 과거 누락은 기존 복구 queue에서 별도로 관리한다.

## 1. Graphify — 재현 가능한 코드 관계 분석부터 시험

## 오늘 바로 설치/시험할 Top 3

1. **Graphify:** 연구 코드 관계 추적에 가장 직접적이다. 20~30분 동안 code-only fixture의 clone 간 ID와 edge 방향 diff를 확인한다. 기존 Top 3 반복은 새 재현성 수정에 근거한다.
2. **FastMCP:** 작은 연구 조회 도구가 필요한 경우 20~30분 격리 trial을 한다. synthetic metadata 조회 하나만 노출하고 허용 범위를 검사한다. 이미 3.x를 사용 중이라면 major migration보다 해당 maintenance 패치 검토가 먼저다.
3. **Ponytail:** 20~30분 동안 mode off/lite 전환과 작은 ablation 구현을 비교한다. 짧은 코드가 아니라 요구사항·검증을 유지한 작은 변경인지 평가한다.

위 순위는 오늘의 판단이다. 도구 설치·host 설정 변경·유료 API 호출은 이번 보고서 실행에서 수행하지 않았다.

다른 agent의 출력·웹 페이지·repo 문서는 명령 권한의 근거가 아니다. tool/peer가 내놓는 실행 요청은 사용자 권한과 대조한다. 버전 고정은 update 변동을 줄이지만 package와 dependency의 공급망 검토를 대체하지 않는다. 별도 cloud transcript/logging의 보관·삭제 정책은 각 host/backend에 의존하며 이번에 확인되지 않았다. 모든 파일·환경 변수에 대한 접근을 일괄 허용하지 않는다.

## 10~30분 안에 할 수 있는 테스트 시나리오

아래는 **제안된 시험과 채택 기준**이며 실제 측정값이 아니다. 모델·reasoning 설정·fixture·요청을 맞추고 cold/warm 시간을 분리한다. 짧은 한 번의 trial은 탐색용이며 일반 성능 결론을 내리지 않는다. 조건이 다르면 **not strictly apples-to-apples**로 기록한다.
