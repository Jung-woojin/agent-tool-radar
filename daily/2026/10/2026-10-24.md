## 1. Nodal-Agents 0.9.8

1. **정확한 이름:** Nodal-Agents 0.9.8.
2. **공식 위치:** https://github.com/Kwintspiracy/nodal-agents · changelog: https://github.com/Kwintspiracy/nodal-agents/blob/main/CHANGELOG.md
3. **종류:** self-hosted agent platform, orchestrator, MCP client/server, automation runtime.
4. **정확히 하는 일:** 여러 전문 agent, model, connector, skill, MCP server, schedule과 approval을 한 로컬 설치에서 운영한다.
5. **해결 문제:** 장기·다중 agent 작업의 process 종료, 비용 한도, credential 저장, 결과 검증을 별도 glue code 없이 묶는다.
6. **지원 client:** 자체 web dashboard; Claude Code·Codex를 coding backend로 사용하고 Nodal 자체를 MCP `run_task` server로 노출할 수 있다.
7. **설치:** Node 24+와 npm 11.6+에서 `npm install -g nodal-agents`; `npx nodal-agents up`도 지원한다.
8. **오픈소스 여부:** 소스 공개. 다만 사용·재배포 조건은 아래 라이선스 문제 때문에 확정할 수 없다.

10. **실행 위치:** dashboard, embedded Postgres, runner는 로컬 self-hosted. 연결한 model·SaaS에 따라 외부 통신한다.
11. **계정/API key:** 선택한 LLM provider key 또는 로컬 Ollama/LM Studio; connector별 OAuth/token이 필요할 수 있다.
12. **read 권한:** workspace 파일, conversation/memory, 연결한 Gmail·Drive·GitHub 등 connector 범위.
13. **write 권한:** workspace, Git, connector가 허용한 SaaS, schedule·agent 설정. ROOT autonomy 수준에 따라 범위가 크게 달라진다.
14. **shell/browser/Git/filesystem/network:** shell·filesystem·Git·MCP·network를 사용할 수 있다. 0.9.8 Windows shell만 OS confinement가 적용된다.
15. **보안·privacy 위험:** 0.9.8은 agent에 email/phone을 보내지 않고 credential을 AES-256-GCM으로 저장한다고 설명한다. 그러나 macOS/Linux 명령은 아직 unconfined이며 Windows도 loopback 공유 등 알려진 경계가 남는다.
16. **최근 update:** v0.9.8은 2026-10-23 공개됐다.
17. **최근 핵심 변화:** Windows job process fence, 전체 delegation을 포함한 run budget, 시작한 child process의 확실한 종료, lazy MCP spawn, MCP SDK security fix가 포함됐다.
18. **활동성:** 0.9.8에 44개 PR과 6개 migration이 포함됐고 10월 23일 후속 CI/release-check fix가 계속 병합됐다.

## 2. Context Pill

1. **정확한 이름:** Context Pill: the source-checked AI scanner.
2. **공식 위치:** https://github.com/agnostify/context-pill · MCP: https://contextpill.com/mcp
3. **종류:** read-only MCP server, Claude Code plugin, Agent Skill, daily release scanner.
4. **정확히 하는 일:** AI tool/model release claim을 출처와 검증 단계·source trust score와 함께 일일 feed로 제공한다.
5. **해결 문제:** AI 도구 뉴스의 복제·과장·출처 부재를 줄이고 agent가 named claim을 다시 조회하게 한다.
6. **지원 client:** Claude Code, Codex CLI, Cursor, VS Code와 Streamable HTTP MCP client.
7. **설치:** `codex mcp add context-pill --url https://contextpill.com/mcp`; Claude plugin·skill 복사 방식도 제공한다.
8. **오픈소스 여부:** scanner, schema, plugin, MCP code가 공개돼 있다.
9. **라이선스:** code는 MIT, feed와 summary는 CC BY 4.0; 인용 원문의 저작권은 원저자에게 남는다.
10. **실행 위치:** 기본 MCP endpoint는 cloud; scanner는 Python으로 self-host 가능하다.
11. **계정/API key:** public MCP는 key·session 불필요. self-host의 optional YouTube/Gemini 경로는 승인 flag와 API key가 필요하지만 현재 기본 off다.
12. **read 권한:** remote feed의 latest/claims/sources 읽기. client workspace를 읽을 필요가 없다.
13. **write 권한:** MCP는 read-only이며 repo·filesystem write를 제공하지 않는다.
14. **shell/browser/Git/filesystem/network:** client는 HTTPS endpoint에 network call만 한다. self-host scanner는 web fetch와 선택적 local `claude` CLI를 사용한다.
15. **보안·privacy 위험:** query가 remote endpoint에 전달될 수 있다. key/session이 없고 write tool이 없어 blast radius는 낮지만 서버 로그 보존 정책은 공식 README에서 명시되지 않았다.
16. **최근 update:** 2026-10-22와 23 daily drop commit을 확인했다.
17. **최근 핵심 변화:** 10월 23일 feed가 갱신됐고 YouTube/Gemini ingestion은 승인 전이라 비활성 상태를 명시한다.
18. **활동성:** scanner는 10월 16일 시작된 신규 MVP이며 일일 drop이 이어지고 있다.
19. **issue/PR 상태:** open issue에는 agent-facing endpoint의 private `tools/list` baseline 제안이 있다. 대형 backlog는 확인되지 않았지만 history가 짧다.
20. **문서 품질:** setup snippet, trust method, missing feature, licensing boundary를 분명히 적어 높다.
21. **코드/테스트 상태:** `test_trust`, `test_tools`, gate, prepush 명령을 공개한다. sandbox smoke test는 아직 미구현이라고 명시한다.
22. **무료/유료:** public MCP는 공식 문서상 key 없이 사용. 향후 요금 정책은 명시되지 않았다.
23. **장점:** 설치가 가볍고 read-only이며 AI Tool Radar 후보 발견과 claim 검증을 분리할 수 있다.
24. **단점:** source score가 아직 초기값이고 첫 claim resolution은 10월 30일 예정이다. 검증 성능의 실측 역사가 부족하다.
25. **Woojin workflow 적합성:** 현재 Radar의 후보 수집 보조로 매우 적합하다. 최종 판단은 계속 공식 repo/release를 직접 확인해야 한다.

**판단:** 오늘의 1순위 저위험 trial. 정확도보다 `출처 있는 후보를 얼마나 빨리 찾는가`를 측정한다.

## 3. pi-agent-browser-native

9. **라이선스:** MIT.

## 4. pg-aiguide

1. **정확한 이름:** pg-aiguide.
2. **공식 위치:** https://github.com/timescale/pg-aiguide · MCP: https://mcp.tigerdata.com/docs
3. **종류:** MCP server, Agent Skills, Claude Code plugin.
4. **정확히 하는 일:** PostgreSQL·TimescaleDB·PostGIS 공식 문서를 semantic search하고 database schema/backfill/index 작업 지침을 skill로 제공한다.
5. **해결 문제:** coding agent가 오래되거나 부정확한 Postgres 문법·운영 패턴을 생성하는 문제를 공식 문서 retrieval로 줄인다.
6. **지원 client:** Claude Code, Codex, Cursor, Gemini CLI, VS Code 및 Agent Skills 호환 client.
7. **설치:** `codex mcp add --url "https://mcp.tigerdata.com/docs" pg-aiguide`; skills는 `npx skills` 방식, Claude plugin marketplace도 제공한다.
8. **오픈소스 여부:** 공개 저장소.
9. **라이선스:** Apache-2.0.
10. **실행 위치:** public MCP는 TigerData cloud; skills는 local instruction. ingest pipeline은 self-host 가능하다.
11. **계정/API key:** public docs MCP는 README상 별도 key가 없다. self-host embedding/ingest는 provider key가 필요할 수 있다.
12. **read 권한:** 공식 database 문서 index 검색. schema exploration skill이 실제 DB에 접근할 때는 별도 DB tool 권한에 의존한다.
13. **write 권한:** public docs MCP 자체는 database write를 제공한다고 명시되지 않았다. skill이 생성한 SQL을 실행하는 권한은 host agent/DB client에 달린다.
14. **shell/browser/Git/filesystem/network:** MCP는 network. skill 설치는 filesystem을 쓰며, 실제 SQL/shell 권한은 연결한 client가 결정한다.
15. **보안·privacy 위험:** 질문이 remote MCP로 전송된다. private schema를 prompt에 넣으면 외부 전송 위험이 있으므로 공식 문서 질문과 내부 schema를 분리해야 한다.
16. **최근 update:** 2026-10-21 MCP 2026-07-28 support, 10월 22일 boilerplate 2.0.1 update를 확인했다.
17. **최근 핵심 변화:** protocol 갱신 뒤 span method와 user-agent가 추가돼 관측·호환성 기반이 좋아졌다.
18. **활동성:** 최근 #172·#173이 연속 병합됐고 그 전 OpenRouter embedding option도 추가됐다.
19. **issue/PR 상태:** type conversion NULL safety, concurrent-index/PK transition, sparse backfill 종료 조건 같은 실전 correctness issue가 열려 있다.
20. **문서 품질:** client별 copy-paste install, use case, plugin/skill/MCP 차이를 잘 설명한다.
21. **코드/테스트 상태:** MCP boilerplate를 공통화했고 ingest planning 문서가 있다. 정확한 coverage 수치는 확인되지 않았다.
22. **무료/유료:** public endpoint는 공식 문서상 무료·keyless로 보이지만 SLA·향후 요금은 명시되지 않았다.
23. **장점:** low-permission, 공식 문서 기반, 설치가 빠르고 DB experiment metadata/backend 개발에 즉시 도움 된다.
24. **단점:** CV model 자체와 직접 관련은 낮고, semantic search 결과가 실행 SQL의 안전성을 보증하지 않는다.
25. **Woojin workflow 적합성:** experiment registry·benchmark metadata·vector/RAG backend를 Postgres로 만들 때 유용하다. read-only docs 질문으로 먼저 측정한다.

**판단:** 오늘 2순위 low-risk trial. 실제 database credential은 연결하지 않는다.

## 5. Open Managed Agents (OpenMA)

1. **정확한 이름:** Open Managed Agents, OpenMA.
2. **공식 위치:** https://github.com/openma-ai/open-managed-agents · docs: https://docs.openma.ai
3. **종류:** managed agent platform/runtime, session API, sandbox and harness orchestrator.
4. **정확히 하는 일:** model·harness·sandbox를 분리해 durable session, event log, recovery, MCP/Skills, browser/shell/file tools를 self-host 또는 cloud에서 운영한다.
5. **해결 문제:** 장기 agent가 sandbox timeout·provider loss·process restart로 실패해도 workspace checkpoint와 event log에서 복구하는 문제를 다룬다.
6. **지원 client:** 자체 API/console, Pi, Claude Code·Codex 등 ACP adapter, Claude Managed Agents/OpenAI Agents API compatibility layer.
7. **설치:** Docker Compose 또는 native Node; Cloudflare/Fly/Vercel 배포 경로와 deployment skill을 제공한다.
8. **오픈소스 여부:** 공개 저장소.
9. **라이선스:** Apache-2.0.
10. **실행 위치:** self-host 또는 hosted cloud; sandbox provider는 local/container/E2B 등 구성에 따라 다르다.
11. **계정/API key:** OpenMA key, model provider credential, 선택한 sandbox/cloud account, web search용 Tavily 등이 필요할 수 있다.
12. **read 권한:** built-in read/glob/grep/web_fetch, mounted memory, 연결한 MCP와 integration.
13. **write 권한:** built-in write/edit/bash, browser action, workspace checkpoint, 연결 service의 write tool.
14. **shell/browser/Git/filesystem/network:** 전부 구성 가능하다. permission policy로 tool별 `always_ask` 등을 설정할 수 있다.
15. **보안·privacy 위험:** 가장 넓은 blast radius를 가진 후보다. provider credential proxy, sandbox egress, checkpoint storage, MCP injection을 함께 검토해야 한다.
16. **최근 update:** 2026-10-21~22 sandbox lifetime/recovery와 error redaction fix를 확인했다.
17. **최근 핵심 변화:** lost sandbox를 probe·replace하고 canonical checkpoint에서 복구하며 turn 중 lease를 갱신한다. model에는 stack trace와 sandbox 내부를 숨기고 full error는 server log에 남긴다.
18. **활동성:** 700개 이상의 commit history와 최근 연속 PR #349~351, chaos test가 확인된다.
19. **issue/PR 상태:** OpenSandbox adapter, egress/credential docs, provider별 self-host guide 등 확장 issue가 열려 있다.
20. **문서 품질:** API event type, built-in tool, sandbox lifecycle, compatibility boundary가 상세하다.
21. **코드/테스트 상태:** sandbox kill·lease failure에 seeded chaos test를 추가한 점이 강하다. 전체 deployment matrix의 독립 검증은 수행하지 않았다.
22. **무료/유료:** source는 Apache-2.0. cloud/sandbox/model provider 비용은 별도이며 hosted plan 가격은 오늘 확인 범위에서 확정하지 않았다.
23. **장점:** long-running research agent의 가장 현실적인 failure인 sandbox reclamation과 partial effect를 명시적으로 처리한다.
24. **단점:** 배포·credential·network·storage 구성이 크고, 작은 개인 workflow에는 운영 부담이 과하다.
25. **Woojin workflow 적합성:** 수시간 논문 재현·GPU job orchestrator로 장기 가치가 있지만 현재 radar 저장만 위해 도입할 이유는 없다. synthetic sandbox-loss test부터 해야 한다.

**판단:** 장기 후보. 격리 환경이 없으면 설치하지 않는다.

## 6. lilbee

1. **정확한 이름:** lilbee.
2. **공식 위치:** https://github.com/tobocop2/lilbee · docs: https://lilbee.sh/
3. **종류:** local RAG/search engine, model manager/runtime, MCP server, TUI/CLI/HTTP library.
4. **정확히 하는 일:** 파일·노트·코드·웹을 local index로 만들고 exact file/line citation과 함께 답하며 GGUF chat/embedding/vision/rerank model을 GPU에 배치한다.
5. **해결 문제:** Ollama·vector DB·crawler·MCP server를 따로 조립하지 않고 local cited retrieval과 model serving을 한 실행 파일에서 제공한다.
6. **지원 client:** MCP-aware agent, Obsidian plugin, 자체 TUI/CLI/API; npm launcher를 통한 MCP 실행도 지원한다.
7. **설치:** standalone, Homebrew, AUR, Nix, Docker, Flatpak, Snap, Scoop, npm, pip/uv 등 다수 경로. beta는 pip에서 `--pre`가 필요하다.
8. **오픈소스 여부:** 공개 저장소.
9. **라이선스:** MIT.
10. **실행 위치:** model·index·retrieval은 local-first. Hugging Face model download와 web crawl에는 network가 필요하다.
11. **계정/API key:** local model만 쓰면 provider key 불필요. Hugging Face gated model이나 외부 provider를 선택하면 별도 credential이 필요할 수 있다.
12. **read 권한:** 사용자가 지정한 file/note/code directory와 crawl URL.
13. **write 권한:** local index, model cache, config/data directory. source repo를 직접 수정하는 도구로 문서화되지는 않았다.
14. **shell/browser/Git/filesystem/network:** filesystem read/write와 network download/crawl을 사용한다. coding agent launch 기능은 별도 agent가 shell/Git 권한을 가질 수 있다.
15. **보안·privacy 위험:** local index에 민감 문서가 복제되고 MCP로 노출될 수 있다. data directory ACL과 bind address를 확인해야 한다. unsigned Snap sideload 경로도 주의가 필요하다.
16. **최근 update:** 2026-10-21 security dependency fix, 10월 22일 timing test deterministic fix를 확인했다.
17. **최근 핵심 변화:** Pillow·aiohttp·certifi·virtualenv·Pygments 등을 올려 19개 OSV와 3개 Dependabot alert를 zero로 만들었다고 commit에 기록했다.
18. **활동성:** 1,000개 안팎의 issue/PR 번호대와 연속 test/security commit이 보이며 개발은 매우 활발하다.
19. **issue/PR 상태:** crawl storage refactor, startup 이후 environment write, fleet warm-up thread leak, RAG integration timeout 같은 open issue가 있다.
20. **문서 품질:** hardware/packaging별 설치, driver 조건, beta·unsigned package 한계를 상세히 적어 높다.
21. **코드/테스트 상태:** OSV Scanner/pip-audit와 다양한 TUI/RAG/fleet test가 확인된다. 일부 timing·resource-lifecycle flake는 아직 open이다.
22. **무료/유료:** MIT self-host. model download·hardware·선택 provider 비용은 사용자 부담이다.
23. **장점:** 연구 PDF·코드·negative result note를 local cited corpus로 묶고 8GB GPU에서도 작은 GGUF/embedding model로 시작할 수 있다.
24. **단점:** active beta, 큰 binary/model download, index storage, hardware별 package 복잡성, on-disk format 변경 가능성.
25. **Woojin workflow 적합성:** 장기 연구 memory와 과거 radar 검색에 직접 유용하다. 작은 corpus로 citation accuracy와 index 비용을 먼저 재야 한다.

**판단:** 오늘 3순위 trial. 원본 연구 폴더 대신 복사한 20개 Markdown/PDF corpus에서 시작한다.

## 오늘 바로 설치/시험할 Top 3

### 1. Context Pill

- **지금 가치:** read-only·keyless라 기존 Codex 환경에 주는 권한 비용이 가장 작다.
- **10~15분 trial:** 최근 24시간 AI tool 10건을 요청하고 공식 release URL이 붙은 비율, 중복 후보 수, 실제 72시간 밖 항목 수를 기록한다.
- **GO:** 10건 중 8건 이상이 공식 원문으로 추적되고 수동 후보 조사 시간을 30% 이상 줄임.
- **KILL:** source trust label이 실제 원문 확인과 자주 충돌하거나 최신 feed가 하루 이상 지연됨.

### 2. pg-aiguide

- **지금 가치:** public documentation MCP라 database write 없이 protocol·retrieval 품질을 시험할 수 있다.
- **10~20분 trial:** `NULL-safe type migration`, `concurrent index`, `pgvector HNSW` 질문 5개를 일반 model 답변과 비교한다.
- **GO:** 5개 중 4개 이상이 정확한 공식 문서 근거를 반환하고 잘못된 SQL 전제가 감소.
- **KILL:** citation이 질문과 무관하거나 response latency 중앙값이 5초를 넘고 반복 호출 이득이 없음.

### 3. lilbee

- **지금 가치:** 과거 radar·논문 note를 local cited memory로 묶을 가능성이 가장 크다.
- **20~30분 trial:** 복사본 Markdown/PDF 20개를 index하고 known-answer 질문 10개를 수행한다.
- **GO:** citation file/line 정확도 80% 이상, 10문항 중 8개가 근거 문서를 찾고 index size와 peak VRAM이 기록 가능.
- **KILL:** 원문 위치가 틀리거나 8GB 환경에서 안정적으로 model+index를 함께 유지하지 못함.

## 전날 대비 생태계 변화

- 전일은 code graph의 stale index와 media input validation처럼 **도구 결과의 정확성**이 중심이었다.
