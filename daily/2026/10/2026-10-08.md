## 오늘의 흐름

전일은 graph 재현성·Windows 설치·agent mode 제어가 중심이었다. 오늘은 **권한이 reconnect와 background task를 넘어 어떻게 유지되는지, long session이 완료 상태를 어떻게 보존하는지, memory capture가 장애 중에도 얼마나 정확히 남는지**로 이동했다.

새 도구를 더 붙이는 것보다 현재 Codex permission smoke test와 memory fixture를 먼저 만드는 편이 이득이 크다. GitHub와 automation 기능은 이미 중복이 많으므로, 추가 도입은 tool 수가 아니라 **실패율·복구율·권한 노출이 실제로 줄어드는지**로 결정해야 한다.
