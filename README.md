# Agent Tool Radar

Daily radar for useful AI-agent tools: MCP servers, plugins, skills, hooks, extensions, connectors, agent frameworks, and developer/research productivity tools.

## Archive structure

- `daily/YYYY/MM/YYYY-MM-DD.md` — daily AI tool radar
- `mcp/` — curated MCP notes and comparisons
- `plugins/` — plugin / extension notes
- `skills/` — agent skills / behavior tools
- `frameworks/` — agent frameworks and orchestration tools
- `watchlist/` — tools worth tracking but not yet recommending

## Daily report criteria

The scheduled radar prioritizes:

- Newly released or meaningfully updated tools
- Real workflow value over star counts
- Official repositories, docs, and marketplaces
- Supported clients (ChatGPT, Codex, Claude Code, Cursor, VS Code, Copilot, etc.)
- Installation and runtime model (local vs cloud)
- API/account requirements
- Read/write permissions and security implications
- Open-source status and license
- Maintenance activity and reproducibility
- A daily **Top 3 to try**

Repeated tools are not promoted again unless there is a meaningful new release or capability change.
